# Security Policy

## Supported Versions

This website is constantly maintained and hosted on the latest stable infrastructure. We regularly update dependencies to ensure security.

| Service | Supported |
| :--- | :--- |
| Main Website (GitHub Pages) | :white_check_mark: Yes |
| External Links | :warning: Use with caution |
| User Data | :lock: No personal data is stored |

## Reporting a Vulnerability

If you discover a security vulnerability or bug on this website, please report it responsibly so we can fix it before it is exploited.

### How to Report

Please send the details of the vulnerability to:

*   **Email:** pyqubit [at] gmail [dot] com (Replace with your email)
*   **GitHub Issues:** Open a new Issue with the "Security" label.

### What to Report

*   Cross-site scripting (XSS) vulnerabilities.
*   Broken access controls or authentication issues.
*   Any suspicious redirects or malicious links.

### Response

I am committed to responding to security reports within **48 hours** and will work to patch any verified issues promptly.
